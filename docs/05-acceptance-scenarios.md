# Pillxa Dispenser 功能验收案例

本文件通过可复现的输入和可见结果验证新实现。案例不要求使用某种编程语言、页面布局或测试框架，也不以复现旧缺陷为通过条件。

本文件验证 00–04、06–07 的当前业务结果。用户已确认的要求保持有效；设计基线提供现行样例，Agent 可以改善实现并同步更新受影响案例。验收关注实际任务是否完成，不要求按钮、页面或内部实现一致。Q 编号用于追溯用户回答；新增 B/P/N 编号分别引用默认决策、页面和交付目标。兼容事实的实机待验证项明确保留。目前只整理文档，没有执行软件测试或实机验收。

## 示例资料与验证层次

以下均为虚构资料：甲院、乙院；长者甲和长者乙；设备 A、B；药品 X 为一种示例整片药，药品 Y 为另一种示例药。用量只是软件计算样例，不是临床建议。

验证分为三类：

- **业务验证**：使用样例资料验证计划、数据归属、记录与查询。
- **设备模拟验证**：输入明确的设备反馈，验证流程和记录关联。
- **实机验证**：确认机械位置、计数反馈、外设及动作顺序。只有模拟通过不能代替这部分。
