# Pillxai Dispenser 数据语义与留存

本文件定义必须留下的事实、身份与历史，是数据含义的权威位置。对象可以合并成物理表或分开存储，不要求独立服务、特定数据库或事件溯源框架。执行行为见 02，操作入口见 06。

## 最小事实链

一项结果应能回答：哪个机构、哪位长者、谁、在哪台机器、依据什么用药版本、为哪些日期时段、计划多少、设备报告多少、人工确认什么、最后是否同步。

处方表达需要；计划保存本次决定；批次和结果保存实际发生的事。三者不能用一份不断覆盖的处方对象代替。

**用户最新确认，2026-10-18**：新系统从新建资料开始，不迁移或兼容旧长者、处方、RFID 绑定、药品图片、历史结果、参数经验和其他旧数据。新生成标签、新建立绑定及新处方参数仍按本文保存；现有 HC-06 协议适配不属于旧业务数据迁移。

## 核心对象

| 对象 | 身份与归属 | 必须能表达的事实 |
| --- | --- | --- |
| 机构 | 稳定机构标识 | 名称、业务时区、默认设置及版本 |
| 人员与成员关系 | 稳定人员标识，院内人员归属一院 | 登录身份、状态、权限、创建人；平台管理身份单独表达 |
| 长者 | 稳定长者标识、机构 | 姓名、床位、照片，不以床号为永久身份 |
| 药品 | 院内稳定标识 | 名称、规格、剂型、单位、图片；同名不等于同一药 |
| 处方药物条目与版本 | 稳定条目标识、长者；新增/复制产生新身份，修改/停止/恢复沿用原身份 | 药品、时段用量、餐食关系、有效期、形态、状态、维护人及生效时间 |
| 识别标签绑定 | 原始标签及规范化标识、机构、长者 | 有效归属、绑定与解绑历史；条码可直接表示长者，不建实体盒号 |
| 终端与设备 | 稳定终端/设备标识、机构 | 绑定关系、型号、连接属性、能力配置、应用及可得固件版本 |
| 设备配置版本 | 设备适用范围 | 协议与物理位置映射、参数策略、来源及生效时间 |
| 处方药物参数档案与版本 | 独立归属一个稳定处方药物条目，不跨条目共用 | 药品规格、投料形态、适用设备范围、当前版本、历史值、来源批次和基础版本 |
| 摆药任务 | 稳定任务标识、机构、长者 | 计划快照、设备与人员归属、阶段、整体结果、最后更新时间 |
| 计划明细 | 任务内稳定明细 | 用药版本、具体日期时段、盘用途、位置、原片量及整数颗粒数 |
| 执行批次 | 稳定批次标识、任务、设备 | 一种药在一盘上的执行，起止阶段、计数、使用参数及实际调整 |
| 执行结果 | 批次及关联计划范围 | 结果类别、机器报告、人工确认、已知与未知范围、覆盖依据 |
| 人工处理 | 稳定事件标识 | 操作、范围、最终数量、原因、人员和时间，关联原异常 |
| 设备事件 | 终端、设备与可判定批次 | 原始反馈、接收时间、命令阶段、关联质量，不伪造硬件任务编号 |
| 光耦采样 | 批次、样本身份 | 原始序号、脉宽、间隔、质量、优化判定及规则版本 |
| 操作历史 | 对象、人员、时间 | 创建、修改、停用、导出、更正等行为及必要的前后值 |
| 附件与导出 | 机构及来源对象 | 文件、格式、生成时间、查询范围、字段说明 |
| 发布与安装记录 | 发布版本、安装实例 | 发布说明、兼容范围、下载/安装结果、原版本与新版本 |

内部记录标识是数据关联手段，不要求工作人员额外手工编号。同机配置与药物学习档案不是同一概念。

## 计划快照

开始时保存完整任务，包括所有盘与药物、用药版本、自动计算的日期时段、位置配置、分盘开关，以及设置中的天数与起点规则及其版本。日期快照不因跨午夜或机构后来改设置而重算，不需要逐次手选日期的记录。

每个批次另外记录本处方条目实际采用的参数版本；该条目后续批次可使用自身的新版本，不能改写已执行批次或其他处方。离线任务保存足够完成本任务的药物资料与参数，行为按 R12、R14。

普通半片用量保存为 0.5 原片，投料形态为半片，执行数量为 1 颗。不能把半片的 21 颗在报表中写成 21 原片。时段和餐食关系分开，睡前不映射为饭前类别。

## 数量与时间

| 数据 | 表达 | 不直接证明 |
| --- | --- | --- |
| 每格计划数量 | 应放多少、单位与形态 | 每格实际落入多少 |
| 设备序号/累计量 | 机器本批报告到多少 | 各格独立实测 |
| 批次完成反馈 | 设备声明该批次完成 | 长者已服药 |
| 人工补入数量 | 人员声明补入多少 | 机器摆了多少 |
| 人工最终确认数量 | 核对范围内最终数量 | 每粒通过传感器的过程 |
| 回收量 | 清出至回收处的数量 | 药盒完成数量 |
| 确认覆盖 | 有依据完成了计划日期时段 | 药仍未服用或已送达 |
| 用药日期与时段 | 计划给哪天哪餐 | 实际执行时间 |
| 设备时间（若有） | 硬件提供的时间 | 本地/中央接收时间 |
| 本地接收时间 | 终端收到事件时间 | 硬件精确发生时间 |
| 中央接收时间 | 服务接收到记录时间 | 执行结束时间 |
| 单调间隔 | 同次运行中的相邻事件间隔 | 跨重启的绝对时间 |

缺失保存为未知，不用零代替。保存时区、单位和来源，不虚构硬件毫秒时间。

现有协议可得粒度见 04：记录逐格计划、本批累计量和完成反馈。正常完成后可以将对应计划标记为完成，来源为“设备批次完成”；不得创建“每格传感器实测值”。部分批次只有累计数时，其余药格实际状态仍未知，待人工核对。

## 采样与参数事实

- 每个样本关联任务、批次、设备、长者药物，以及应用、算法和可得固件版本。
- 原始脉宽数值不改写；单位未证实时明示，不擅自转成药片面积。
- 接收原始数据与筛选判定分开保存，记录重复、乱序、缺号、无效范围和是否用于优化。
- 不用插补值冒充机器原始值；若后续分析产生估计结果，应另存方法和版本。
- 记录实际下发的电机/舵机值、确认情况、手动调整时间与值。下发值不是实时实测速度。
- 没有样本的跳过或中断仍有批次摘要。
- 学习版本记录来源样本范围、有效样本数、统计量、策略版本和适用范围。
- 每份处方的各药物条目分别关联参数与样本。同药同规格也不合并档案；过时回传保存为执行历史，不覆盖当前参数，处理规则见 R14。

## 历史和更正

| 变化 | 保存方式 |
| --- | --- |
| 改名、换床 | 当前资料变化；旧任务身份与必要的当时显示值可解释 |
| 改规格、用量、疗程或停药 | 新用药版本；旧计划和结果保留 |
| RFID 重新绑定 | 新有效关系，旧任务仍指向当时对象 |
| 布局或本处方条目参数变化 | 保存新版本，不改变旧批次及其他条目 |
| 记录写错 | 追加更正及原因，原事实和更正关系保留 |
| 停用账号 | 账号不可继续使用，历史操作身份仍可查询 |
| 同一事实重复上传 | 中央保留一份，不再增加覆盖或完成数量 |

## 长期留存

**用户已确认 Q12**：所有数据长期保留，不自动清理。

**用户已确认，2026-10-18**：设备中断时，人员可显式选择“结束此次分药（不记录）”，确认后删除本次任务、结果、设备反馈、关联审计和本机诊断数据；不是仅从列表隐藏，也不保留中止记录。这是长期留存的人工例外，不改变自动清理规则；其他任务、长者、处方及其历史保持原有留存。删除的任务不产生覆盖；本机和中央删除顺序与失败重试见 02 R12。既有离线备份不由应用逐份回写，备份恢复时仍须核对数据时间与已取消任务，防止重新计入覆盖。

**用户最新确认**：主动关掉软件停止并取消当前任务，不计完成或覆盖；是否还要等同上述入口彻底删除全部记录，尚待明确。明确前保留恢复和核对证据，不自动删除。系统强杀、崩溃及断电不能自动视为已经确认取消，须恢复核对。

包括业务资料与版本、计划结果、各处方参数及历史、原始光耦采样、操作历史、设备及诊断记录、照片及已保存附件。无按年龄自动删除或只保留最近若干条的政策。归档可以改变存储位置，但仍须可查询或导出，不能以归档名义丢弃原数据。

这一要求针对有保存意义的事实、原始采样及文件；不要求把每次屏幕刷新、内存对象或同一上传重试复制成新的业务记录。备份交付要求见 07。

## 机构归属

角色规则见 01。服务器对每次访问校验机构，列表、按编号读取、搜索、统计、图片和导出遵守同一范围，不仅前端过滤。

同院长者、任务、设备、参数关系不得误连其他院对象。新标签与绑定必须表达可校验的长者身份和机构归属，不兼容旧六位条码或旧绑定。平台管理员有跨院管理权限，实际查询仍带当前所选机构。

本机未结束任务和待同步结果始终保留原机构。切换管理视图不改变它们的归属或重新下发动作。数据隔离不预先规定一院一数据库。

## 本地与中央记录

中央确认任务归属；终端负责本机物理执行和原始记录。每项事实产生稳定身份，本地保存后补传同一事实，中央确认后标记同步完成。

持续保存启动、命令、进度/采样、完成和人工处理，不能只在返回首页时汇总。具体批量落盘方法后续实现；除 R12 已确认的显式删除流程外，进程重启不得把整个已开始任务抹掉，无法确认的尾部事件标为未知。

断网只继续既有任务，按 R12。补传只更新执行事实，不覆盖当前处方；参数结果只关联原处方条目，按 R14 检查版本与投料形态。同步失败指出范围并允许重试，重复上传不能重新执行设备动作。

## 查询、统计与导出

按机构、长者、日期、药物、设备、操作人、结果筛选；支持分页和全量匹配范围导出，分页不限制留存。

| 指标 | 固定口径 |
| --- | --- |
| 任务数 | 去重任务身份；取消、部分完成与成功分列 |
| 完成人数 | 时间范围内至少一个全部完成任务的去重长者数；不是日志行数 |
| 批次数 | 去重实际执行批次；人工处理另列 |
| 药物条目数 | 按长者用药条目去重；不等于药品种类数 |
| 颗粒数/原片量 | 分单位和形态汇总，不能混为一列 |
| 任务完成率 | 全部完成任务数 / 范围内已结束任务数；零分母显示无数据 |
| 设备运行/等待/暂停/整体时间 | 按已记录阶段分别计算；无法确定的间隔注明缺失 |

导出至少带身份关联、日期时段、单位/形态、来源、版本、结果及字段说明。采样导出带原始值、序号、时间、质量和算法判定，不能只有过滤后的数列。长期数据量的测试与操作目标见 07。
