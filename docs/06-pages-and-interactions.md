# Pillxai Dispenser 页面与操作流程

本文件把业务规则落到工作人员可操作的页面，不规定前端框架、像素布局或必须有多少独立窗口。权限见 01，默认值见 00，状态与计算以 02 为准。以下提供当前交互起点；Agent 可以根据工作人员完成任务的体验合并页面、缩短步骤或调整按钮，保持用户确认的业务结果并验证实际操作。首版面向 Windows；后续 Android、网页端及 iOS 可按屏幕与输入方式调整布局，沿用相同业务含义和允许动作。设备控制入口按客户端实际连接能力提供，不能因为页面可复用就假定平台已具备机器控制能力。

品牌显示采用重新绘制的[方形主标志](../assets/branding/pillxa-mark-rounded.png)和收紧空白画布的[文字标志](../assets/branding/pillxa-wordmark.svg)：登录页和常规主导航使用文字标志，紧凑导航及应用图标使用方形主标志。主标志使用圆角白底，只有圆角外部透明，深浅背景下保留底板及字形内部白色区域；Windows 小尺寸图标在两个 L 之间保留清晰白色间隔；文字标志按图形实际比例显示，不以原 SVG 的空白画布计算大小。窗口及应用名称为 Pillxai Dispenser。蓝色仅用于主按钮、选中态、焦点和进度条等小范围强调；页面与大卡片背景保持中性色，不大面积铺蓝色。成功提示使用蓝色或中性灰，异常继续使用橙色或红色；界面不再保留绿色提示、绿色药格或绿色装饰。窗口请求 Windows 原生圆角，最大化等状态遵循系统呈现；卡片和输入控件使用圆角。关闭窗口直接退出，不驻留托盘，关闭本应用拥有的后台进程。正在执行时先请求暂停并保存已知进度，重开后核对现场。

## 持续可见的信息

工作区始终显示当前机构、人员、本机设备与连接状态；有任务时显示住民、当前药物/盘、进度及返回执行入口。右上角提供下载图标及更新状态。

每个列表区分读取中、空结果、失败与成功；每次保存区分保存中、已保存和失败。失败保留已输入内容。弹窗和快捷键作用于当前设备任务，不改变其他终端。

平台管理员切换机构只切换管理视图；本机任务不随视图迁移。正在执行时可查资料，保留任务状态条；更新和退出执行相关处理不能藏在无提示的页面跳转里。

## P01 登录、平台与账号管理

| 步骤 | 信息与操作 | 完成条件 |
| --- | --- | --- |
| 登录 | 账号、密码，“登录” | 显示所属机构；平台账号进入机构列表 |
| 平台建院 | 机构名称、默认时区，“创建机构” | 生成机构及设置，可继续“添加院内管理员” |
| 建管理员/员工 | 显示名称、用户名、初始密码、院内权限 | 保存成功后账号可用；冲突明确到用户名 |
| 院内账号列表 | 状态、权限，“新增”“重置密码”“停用/恢复” | 仅作用于所选本院，历史操作人不消失 |
| 切换机构 | 平台管理员选择机构 | 列表、附件与统计重新加载；本机执行入口保留原归属 |

无平台身份不显示创建机构或切院入口；不能只通过隐藏按钮实现权限。

## P02 工作台与住民资料

“今日工作”以准备清单为主要区域，本机当前任务及院内正在进行的任务为辅助区域。清单支持待准备、提前准备、全部住民及姓名/床位搜索；住民项显示姓名、床位、已有覆盖、本次建议日期、待处理原因、占用机器。提醒和计划由中央按 R01 生成，模拟记录不计入实际覆盖。读取失败显示失败，不用零人数代替。点击“核对计划”直接进入该住民的计划预览；有未结束任务时提供查看原任务入口，其他机器仅查看进度。

住民列表支持姓名/床位搜索、在院/已离院筛选、“添加住民”“导出标签”。搜索与筛选后，右侧详情只能展示当前列表内的住民。详情分为当前用药、资料与药盒、摆药历史；用药使用紧凑条目排列，突出药名规格、时段剂量、餐食要求和疗程。已停止用药可展开，出药设置放在有权限人员的更多操作中，版本不占日常列表。住民保存后直接可进入处方维护，不必先连摆药机。

资料表单：姓名、完整床位文本、照片、在院状态；自动编号只读。空床位允许保存，同院有效床位冲突定位到另一住民。

## P03 处方编辑

逐条显示药名、规格、图片、各启用时段数量、餐食关系、起止期间及状态。提供“新增药物”“保存修改”“停止用药”和历史版本。

选择整片或预切半片后，输入和预览明确区分原片用量与机器颗粒。未启用睡前时不显示可执行睡前格；若历史条目已有该时段需求，先解决布局，不静默忽略。

表单依次组织药物信息、每次用量、用药期间，图片可选，长期和有限疗程明确选择。切换整片/半片时保留原用量，形态不匹配时定位提示并阻止保存，不能自动改写剂量。保存前显示具体校验错误；保存失败保留输入。半片改整片、药物或规格改变时提示“出药设置待调整”，其他处方参数不受影响。普通改日期或时段不会强制重新学习。

## P04 标签导出

勾选住民，输入每人份数，显示总张数、A4 页数；生成成功后在应用内显示按页排列的标签预览，包括姓名、床位和实际身份条码，预览与导出共用标签身份及版式定义。无需依赖客户端的 PDF 内嵌阅读能力。点击“导出 PDF”保存文件，实际打印尺寸以 PDF 为准。生成期间固定选择对象和份数，失败保留选择；没有打印机或精臣服务也可导出。

条码内容用于住民身份识别，版面显示姓名和床位。生成成功仅表示文件成功，打印由常规 PDF 工具完成。

## P05 计划预览与领取

页面顶部显示住民、按设置自动计算的覆盖起止日和天数、所用起点规则，以及餐食分盘开关。日期、天数和起点规则用于核对，不放逐次选择控件；有设置权限时提供“查看/修改覆盖设置”，修改保存后重新生成未开始计划。

宽面板中通过盘用途切换预览，中部为真实日期列、服药时段行、每格药名、规格与计划颗粒数，时段列在横向滚动时固定；侧面列逐药投料形态、总颗数和半片的原片等价量。日期列显示月日及星期，星期不能代替日历日期。明确说明日期沿用机构规则；本次分盘开关保留。

底部操作：

- “返回修改”：不占用机器。
- “领取并核对药盒”：联网、计划有效且本机空闲时领取，成功进入识别。
- “取消领取”：仅未启动时可用，释放本次归属。

处方或布局变化显示“计划已变化，请重新生成”；没有待摆药物显示原因。任务已被其他电脑领取时显示设备与人员，不让工作人员反复尝试下发。

## P06 识别与首次开始

首版先选任务，点击“领取并开仓放盒”后保存任务并请求开仓，进入统一“药盒识别”组件。开仓失败显示重试入口；未连接机器时提示去设置连接。请求成功后显示“请将药盒放到轨道上，系统会自动识别所属住民”，后台摄像头与 RFID 同时观察，不显示来源选择、扫码输入框或摄像头画面，不要求再次点击扫描。将来空闲时识别住民进入计划也必须遵循先开仓再放盒的顺序。

组件只展示准备放盒、等待放盒、核验通过或需核对；匹配成功显示姓名与床位。识别设备部分不可用时，另一来源仍可完成核验；确实无法识别时显示统一设备重试入口。模拟模式单独保留“模拟放入本人的药盒”，真实模式没有人工指定住民冒充识别的入口。开仓状态由本机保存，页面重载不重新下发开仓命令。

匹配成功、计划有效、归属已确认、本机就绪且完整资料已在本地保存后，“开始本药”可用。启动前新发现版本变化返回预览；断网时说明等待网络恢复。

不匹配保留当前任务住民，提示更换药盒；未绑定标识提示到住民资料完成绑定，并展示具体标识和“复制标识”按钮。RFID 显示可直接用于绑定的完整十六进制 UID，保留前导零，不包含 `UID:` 前缀；条码显示完整标签内容。标识可手动选中复制，多个未绑定标识分别列出，取出后随对应观察消失。有另一有效来源匹配时可继续，同时保留未绑定标识提示。冲突按 R06，不能一键忽略变为成功。识别成功仍持续观察到首次开始，取出或更换药盒时更新核验结果。

保存住民的 RFID 绑定后同步本机识别资料；仍在轨道上且本次会话已观察到的标识重新核验，不要求重新领取任务，不下发机器动作。已取出的标识不因保存绑定重新变为在位。

## P07 执行台

主要区域只突出当前住民、药物、图片、规格、投料形态、目标与累计进度。显示“准备中”“可投入当前药物”“等待完成反馈”等实际阶段。准备下一药或换盘时，主卡、图片、开口控件和开始按钮均指向下一批药物，预览计数从零显示，不能继承上一药的计数或最近开口值；上一药显示为处理摘要。药格默认折叠为“查看本盘摆药计划”。本机命令成功后立即刷新本机状态，中央资料刷新在后台进行，连接失败不能阻塞暂停、恢复等本机控制。

| 当前情况 | 可用操作 | 结果 |
| --- | --- | --- |
| 本药尚未启动 | 开始本药 | 保存启动并执行，随后可投料 |
| 本药执行中 | 暂停、调整开口、跳过、结束当前工作 | 显示请求及反馈；不提前宣称动作成功 |
| 暂停已确认 | 继续摆药、结束当前工作 | 按已保留进度继续，或进入结果核对 |
| 本药完成，尚有下一药 | 开始下一药 | 工作人员更换药物后主动开始，无“投料完成”按钮 |
| 本盘完成，尚有下一盘 | 进入换盘 | 显示下一盘用途，开仓等待换盘 |
| 所有药处理结束 | 查看结果、取盒 | 进入结果页 |

收到进度反馈更新 N/T；达到 100% 尚未收到完成时写“等待设备完成”，不显示总任务成功。

工作台提供“阀门舵机 · 药物名称”组件：滑块与数值输入同步，使用 `0–1` 设备刻度、步长 `0.01`，不标注角度；数值越小开口越大，机械位置以现场为准。连续调整时等待最后一次变化，停止约 400 毫秒后自动下发当前有效值；松开滑块、数值输入失去焦点或按 Enter 时立即提交。没有“应用”按钮，初次显示、页面重载和重新连接不自动发送初值。准备下一药或换盘时标题明确指向下一药，提交携带任务及批次身份，药物已变化时保留输入并提示重新核对。

准备、执行、暂停和异常核对阶段可调整；未连接时只保留输入，不发送；离开页面、药物变化、断开连接或输入无效会取消尚未下发的调整。发送期间仍可继续调整，按顺序发送并只保留最新待发值，不积压中间位置。显示最近下发值，模拟操作明确标记。调整不重置计数、不重发矩阵、不自动恢复暂停，也不自动保存处方参数。启动前手动值沿用于本次药物；下一药使用自己的参数，需供以后任务沿用时到该处方的出药参数中显式保存。

## P08 异常与人工处理

统一面板包含当前设备、住民、药物、计划范围、已知计数、异常和下一步。按异常显示相应动作：

- 堵转：列出待解除电机，人员处理后逐项“已清理，解除”。
- 计数异常或中断：选需核对的日期/时段范围，输入最终数量或选择“已核对全部按计划补齐”，保存为人工结果。
- 跳过：记录原因及未完成/未知范围，进入“等待机器退出当前药物”，依次等待停转 ACK、退出 ACK 和 DONE，再进入下一药或开仓取盒。等待中不开放继续投料及舵机调整；反馈迟迟未返回时可用“反馈未返回，转入现场核对”，保留计数及处理请求事件，核对后重新处理，不自动重发数量矩阵。
- 工作台提供独立“跳过当前药物”入口，默认选择“跳过，未完成”，确认按钮明确写“确认跳过，记为未完成”；人工补齐使用独立的确认文案，避免把跳过误选为补齐。
- 重连：中断面板保留最后已知进度，提供串口刷新、选择原机器串口和“尝试重连”。端口打开后，用户可“继续分药”，先确认机器未断电/复位、原药盒及药物未换且原批次进度仍保留；只发送恢复命令，不从头重摆。已知复位转入人工核对。
- 结束此次分药（不记录）：设备中断或异常核对时可选，独立弹窗说明删除本次任务、结果及设备反馈，要求确认机器已安全停稳且药盒和药物已妥善处理。确认后无需硬件应答，先锁定本机任务再删除中央、本机数据；失败保留删除阶段并提供重试。完成后回准备清单，历史及导出不再包含该任务，不计入完成覆盖。该操作不发送开仓或收仓命令。
- 结果仍不清楚：允许保留“待核实”，不能要求人员编造数字才能退出。

正常机器完成不弹出人工数量表单。无二级审批。

## P09 换盘、结果与取盒

换盘页面明确显示已完成与下一盘用途、同一住民及日期。完成本盘后机器开仓，清除上一盘的识别结果，再使用统一“药盒识别”组件自动核验。人员放好下一盘且识别通过后点击“已换好，继续摆药”；下一药仍显示药物提示。未识别、识别冲突或另一住民药盒时不能继续。

结果页按药列机器完成、人工完成、跳过未完成或待核实，显示任务总体结果、待同步状态及取盒状态。Windows 当前实现提供“已取出药盒，收回轨道”：人员先实际取盒，再点击按钮发送关仓命令，写入失败保留本页和原摆药结果供重试，未连接设备时按钮不可用；写入成功记录收仓请求及人工取盒来源，不声称测得机械位置。取盒阶段保留“重新开仓”，只重发开仓请求，不改变药物结果、计数或计划。最后一药跳过同样进入开仓取盒，但整体结果为部分完成。后续自动检测取盒时，正常检测后收仓；检测失败提供“重试检测”和人工入口。机器就绪的确认属于设备能力，不能用页面消失代替。

## P10 处方参数管理

从具体处方的药物条目或执行结果进入参数档案，显示所属住民、处方条目、当前值、版本、来源设备和投料形态。不同处方即使同药同规格也各自独立。

提供“调整参数”“保存参数”“查看历史”和学习开关。保存只作用于当前处方药物条目。

药物、规格或形态变化时提示重新调整。保存期间发现版本变化，保留本次输入并提示刷新核对后重新调整，不静默覆盖。离线批次结果可查，但过时学习值不会覆盖当前参数；具体规则见 R14。

## P11 记录查询

筛选机构范围内的住民、摆药日期、药物、设备、人员、结果及真实/演练环境。日期按机构时区计算首尾日边界，搜索支持姓名或床位；点击查询生效。排序支持时间正序和倒序，分页与导出使用同一组服务端筛选条件，不能只筛选已加载页。列表突出住民/床位、摆药时间、覆盖日期、设备名称和结果。详情采用宽抽屉，依次展示整体结果、逐药结果、人工处理经过；原计划和技术详情按需展开。模拟记录持续标记，缺失结果、未知结果不能标成完成。

提供“导出当前筛选结果”和“导出原始采样”。日期时段计划与设备累计报告分区标明，不能将计划格显示成逐格实测。导出状态可见，后台生成长导出时不阻塞执行台。

## P12 设置、诊断与更新

机构设置只由管理员维护；本机连接配置与参数策略分开。保存时显示适用范围与生效时点，默认值不在本页面另行定义，引用 00。

设置嵌入主工作区，原有主导航、机构选择、账号信息和服务状态继续显示。主导航右侧为设置页内部的“设置”标题、中文搜索与分类导航，再右侧为当前分类的标题、说明和分组列表。工作人员可直接使用主导航切换到其他工作页面，不设置“返回工作空间”或退出设置步骤。

分类分为两层：“机构设置”包含常规、摆药规则、药盒布局；“本机设置”包含设备连接、软件更新。常规显示当前养老院、账号和机构时区；摆药规则维护覆盖天数、漏摆起点、提醒和餐食分盘；药盒布局维护睡前时段和实体格的顺序。每个列表项左侧说明用途，右侧放输入框、选择、开关或操作按钮。

分类切换和搜索保留尚未保存的机构设置。统一显示“有未保存的更改”“保存中”或“机构设置已保存”，提供保存与撤销。工作人员只读机构规则。本机名称、串口连接和更新各自显示操作状态，不通过保存机构规则触发。搜索匹配分类及设置关键词，未找到时显示空结果。设备连接区说明 HC-06 先完成 Windows 配对，再选对应出站串口；区分端口已打开和已收到有效反馈，不将连接成功标成实机验证通过。传输配置与通信依据统一见 [04](04-device-contract.md#现有传输方式)。
