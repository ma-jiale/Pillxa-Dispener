# Pillxai Dispenser

面向养老院的处方管理与摆药系统。工作人员维护长者用药，核对摆药计划，识别药盒，逐药执行并查询实际结果。

## 当前状态

2026 年 10 月 18 日，用户确认使用 Flutter 重新开发，后端采用 Python + FastAPI，首发 Android 平板并直接连接 HC-06。后续支持手机、平板、Windows 和 iOS；各平台硬件能力分别验证。已建立 `apps/client` Flutter 客户端交互预览，采用用户确认的极简风格作为唯一界面；移除方案切换栏和其他方案，继续完善处方管理。处方管理、摆药与设置使用内存演示数据。FastAPI、HC-06、后台生命周期和生产数据持久化尚未实现。运行入口、实际验证结果、平台构建状态与当前限制见[客户端说明](apps/client/README.md)。

各养老院访问开发者维护的统一公网服务，平板由机构管理，首发由开发者下载安装包并手动安装。新系统使用新建资料，不迁移或兼容旧长者资料、处方、RFID 绑定、药品图片、历史结果和参数经验。用户认可聚焦版的低信息密度与三个入口侧边栏；当前 GUI 按“摆药”“处方管理”“设置”排列，登录后默认打开摆药，直接切换，不设返回页。主体采用白色或浅灰背景，允许灰色主背景配白色卡片，灰色用于区分层级。黑色仅为默认强调色，可由用户个性化调整；药品图片保留原本色彩。界面已确定为单一极简风格，沿用横向侧栏与固定浅灰选中态，继续完善处方管理。
