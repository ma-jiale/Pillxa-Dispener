UI 要求聊天参考 · 9 张用户原型 · 9 张查看当前界面与开发指南

已明确提出的要求

视觉气质

现代、简洁、有高级感。降低信息密度，只突出工作人员当前需要的信息，避免复杂、拥挤。

配色

主体可采用白色或浅灰背景，灰色区分层级；黑色是可自定义的默认强调色。药品图片保留原本色彩。

品牌

界面左上角放置 Pillxai 字标，以及具有设计感的简约黑色图标。

导航

当前侧栏采用图标文字横排与较长圆角矩形，选中背景固定浅灰，不随强调色变化。设置用齿轮、摆药用胶囊，处方管理保留原图标；摆药放在处方管理上方并作为默认页，设置下方显示圆形账户头像与退出菜单；三个入口直接切换，不需要返回页。

平板比例

首发 Android 平板，当前优先照顾平板体验。字体、图标和控件不要显得过大，按正常平板 UI 比例调整。

参考使用

用户自己的原型与网站原型都值得借鉴。第 05 张只参考比例，不参考配色与结构；第 06 张参考 UI 组件风格；新增第 16 张用于横向侧栏与浅灰选中态。保持简洁、灰白层级，其他强调色可自定义。

统一风格

用户已确认当前极简版为唯一界面，移除底部方案栏和其他方案，按同一风格完善处方管理、摆药与设置。用户原型和参考图继续保留。

当前采用用户确认的极简风格，已结束方案比较。打开交互预览 · 查看界面截图 · 运行与验证说明。三个模块仅有内存演示交互，尚未接入 FastAPI、HC-06、后台生命周期和生产持久化。当前侧栏采用第 16 张参考的横向图标文字和浅灰选中态，继续保留当前药物重点、简短下一药预告、三入口直接切换和品牌区；字号、圆角、阴影与间距仍可改进。以下参考用途除明确标注“用户明确”的内容外，是对参考图的设计提炼。
